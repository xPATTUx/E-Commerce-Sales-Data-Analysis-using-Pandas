# E-Commerce Sales Data Analysis using Pandas

## Overview

This project analyzes an e-commerce sales dataset using **Python and Pandas**. It focuses on exploring sales data and extracting useful insights related to products, categories, cities, regions, and payment methods.

The analysis demonstrates essential data analysis techniques such as data selection, filtering, sorting, grouping, and aggregation.

## Objectives

* Load and explore an e-commerce sales dataset.
* Understand the structure and characteristics of the data.
* Perform data selection and filtering.
* Sort orders based on sales and quantity.
* Analyze sales across different categories and cities.
* Identify top-performing products.
* Compare different payment methods.
* Calculate total, average, highest, and lowest sales.
* Determine total quantity sold and number of orders.
* Generate meaningful observations from the analysis.

## Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Jupyter Notebook / VS Code**

## Dataset

The project uses an e-commerce sales CSV dataset containing information about orders, including details such as:
